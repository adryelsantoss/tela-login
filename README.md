# Tela de Login

Uma interface moderna de autenticação desenvolvida com React, Vite e Styled Components.

## ✨ Funcionalidades

- Tela de Login e Cadastro
- Overlay animado com transição suave
- Layout responsivo
- Styled Components + ThemeProvider
- Design minimalista e moderno
- Componentização em React

## 🚀 Tecnologias

- React
- Vite
- Styled Components
